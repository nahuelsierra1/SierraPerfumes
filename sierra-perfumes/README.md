# Sierra Perfumes — Catálogo

## Cómo usar

1. Instalar Node.js.
2. Abrir esta carpeta en una terminal.
3. Ejecutar `npm install`.
4. Ejecutar `npm run dev`.
5. Abrir la URL que indique Vite.

## Cambiar productos

Editar `src/products.js`.

Cada perfume tiene:
- id
- name
- brand
- category
- price
- image
- size
- type
- notes
- description
- stock
- featured

## Cambiar datos del negocio

Editar `src/config.js`.

MUY IMPORTANTE: reemplazar `STORE.whatsapp` por el número real de WhatsApp en formato internacional, sin `+`, espacios ni guiones.

Ejemplo Argentina:
5492231234567

## Publicar

Se puede desplegar en Netlify, Vercel o cualquier hosting que soporte una app Vite.
